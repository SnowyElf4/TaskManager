# TaskManager v0.4

Консольный менеджер задач на Java с поддержкой нескольких пользователей и постоянным хранением данных в JSON-файлах.

Проект демонстрирует базовую MVC-подобную архитектуру с разделением:

* пользовательского интерфейса
* бизнес-логики
* слоя хранения данных

## Возможности

* Регистрация пользователей
* Выбор активного пользователя
* Создание задач
* Просмотр всех задач текущего пользователя
* Отметка задач как выполненных по ID
* Постоянное хранение пользователей и задач в JSON-файлах
* Каждая задача жёстко привязана к конкретному пользователю
* Защита от доступа к чужим задачам

## Архитектура

```
src/
 ├─ appconfig/
 │   └─ AppConfig.java
 │
 ├─ ui/
 │   ├─ MenuController.java   // управление флоу приложения
 │   ├─ MenuView.java         // вывод в консоль
 │   └─ InputReader.java      // безопасный ввод данных
 │
 ├─ service/
 │   ├─ UserService.java
 │   ├─ TaskService.java
 │   └─ StorageService.java  // работа с JSON
 │
 ├─ user/
 │   └─ User.java
 │
 ├─ task/
 │   ├─ Task.java
 │   └─ IdGenerator.java
 │
 └─ Main.java
```

### Ключевые принципы

* `MenuController` управляет логикой переходов между меню
* `MenuView` **ничего не знает о логике**, только выводит
* `Service`-классы не работают с вводом/выводом
* `StorageService` — единая точка чтения и записи JSON

Данные **не теряются** между запусками приложения.

## Установка и запуск

1. Клонировать репозиторий:

```
git clone https://github.com/SnowyElf4/TaskManager.git
```

2. Перейти в директорию проекта:

```
cd TaskManager
```

3. Скомпилировать проект:

```
javac -d out $(find src -name "*.java")
```

4. Запустить приложение:

```
java -cp out src.Main
```

## Использование

При запуске:

* если пользователей нет — предлагается регистрация
* если пользователи существуют — можно выбрать активного

### Главное меню

* создание задачи
* просмотр своих задач
* отметка задачи как выполненной (по ID)
* смена пользователя
* выход из приложения

Каждый пользователь видит **только свои задачи**.

## Пример работы

Регистрация пользователя:

```
Write name: SnowyElf
User created.
```

Создание задачи:

```
Write task name: Уборка
Write description: Протереть пыль
Task created.
```

Просмотр задач:

```
ID: 12345678
Task name: Уборка
Description: Протереть пыль
Is done: false
```

Отметка задачи как выполненной:

```
Enter task ID to mark done: 12345678
Task marked as done.
```
